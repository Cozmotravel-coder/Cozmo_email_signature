# Multi-Brand Email Signature Generator

A modern, dynamic email signature generator built for Cozmo Travel and its subsidiary brands.

## Features
- Generates high-quality, pixel-perfect HTML email signatures without external stylesheets.
- Dynamic responsive brand buttons to switch between subsidiaries (e.g. Cozmo, Air Arabia). 
- Automated Admin controls (Password protected) to add new brands, change logo URLs, resize dynamic layouts, and manage global office locations.
- Seamless single-click "Copy to Clipboard" support for Outlook and Apple Mail.
- Fully local execution (no backend required).

## Local Development
Run a local Python web server to view the app:
\`\`\`bash
python3 -m http.server 8080
\`\`\`
Then navigate to \`http://localhost:8080\` in your browser!
